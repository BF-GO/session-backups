# Changelog

All notable changes to this project are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [2.0.0] - 2026-07-28

### Added

- WXT and React Manifest V3 implementation with popup and full session library.
- Automatic, change-triggered, manual, and imported recovery points.
- Whole-session, per-window, and selective tab restore with pinned tabs and supported tab groups.
- Typed local storage repository, strict schema validation, retention, and deterministic deduplication.
- Verified migration from v1.7 storage and validated JSON import/export.
- Privacy, architecture, schema, migration, threat-model, contribution, and security documentation.
- Continuous integration, coverage reporting, and reproducible ZIP/checksum releases.
